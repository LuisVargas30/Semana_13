## Descripción del problema resuelto
Este proyecto resuelve el cálculo del monto total a pagar por la compra de un producto según su precio unitario y la cantidad de unidades adquiridas. El programa está desarrollado en Python dentro del archivo `Calculocompra.py` e implementa una función que recibe ambos valores como parámetros, realiza la multiplicación correspondiente y devuelve el resultado para ser mostrado en consola.
